# Pavito

Prototipo de mercado de ropa usada para Venezuela, con el modelo de Vinted:
el vendedor no paga comisión y el comprador paga una tarifa de protección.

## Qué incluye (versión 4 del prototipo)
- Logo, pantalla de bienvenida y registro con teléfono (verificación simulada, código 123456)
- Anuncios con foto, categorías, búsqueda y filtros
- Precios en USD y Bs, con tasa editable
- Favoritos, chat, ofertas y contraofertas
- Pedidos con Pago Móvil, pago retenido, envío, liberación y reseña escrita
- Perfil: mis compras, mis ventas, mis anuncios (editar, destacar, vendido, eliminar), datos de entrega, ajustes
- Perfil público del vendedor con reseñas y anuncios
- Ayuda "Cómo funciona" y borrador de términos y privacidad

## Archivos
- `la-percha.html`: todo el prototipo en un solo archivo. Es un fragmento sin
  `<html>` ni `<head>`: se completa al publicarlo como artefacto de Claude.
- `assets/logo.svg`: logo de Pavito (base para el icono de la app)
